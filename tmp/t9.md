## What to build

The Operator can tune the daemon's health judgement from the environment without rebuilding it. Every numeric threshold that classifies a sample, and both hysteresis counts, take an environment override under a common prefix.

Defaults reproduce today's behaviour exactly, so an Operator who sets nothing sees no change. This is what makes the judgement usable across machines with different memory ceilings and load profiles.

## Acceptance criteria

- [ ] Every threshold the evaluator uses to classify a sample is settable from the environment.
- [ ] Both hysteresis counts — samples to assert a Verdict and samples to clear one — are settable from the environment.
- [ ] With nothing set, every value equals what the code used before this ticket, and the existing health tests pass unchanged.
- [ ] Overrides use one consistent, documented prefix.
- [ ] A malformed or missing value falls back to the default rather than failing to start or producing a nonsense threshold.
- [ ] A hysteresis count of one behaves as no hysteresis at all.
- [ ] A snapshot missing a measurement still means no signal from that dimension, not a failing one.
- [ ] The available settings are documented where the project documents its other environment variables.

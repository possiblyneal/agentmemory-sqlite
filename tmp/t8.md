## What to build

The Graph Snapshot stops carrying Provenance. It exists to make reads cheap by holding a bounded view of the busiest Entities and their Relations; carrying every source id along with them makes it grow with how often things are mentioned, which is the opposite of its purpose.

Provenance does not disappear from the system — it stays on the Entity and Relation records themselves, which is where anything asking about origin should look. Only the derived, disposable Snapshot sheds it.

## Acceptance criteria

- [ ] The Snapshot's Entity entries carry no Provenance.
- [ ] The Snapshot's Relation entries carry no Provenance.
- [ ] The underlying Entity and Relation records still carry theirs, unchanged.
- [ ] A consumer that needs Provenance for something named in the Snapshot can still obtain it by reading the record.
- [ ] The Snapshot still carries everything else it did — the same Entities, the same Relations, the same statistics.
- [ ] A stored Snapshot written before this change is still readable and is replaced by a projected one on the next write.

# 2026-10-18 — sdebench (boltons) findings log

**Bench:** sdebench, AMB harness, 61 boltons tasks (conversation, `-history`, `-amended`)
**Agent and Summaries:** Claude Sonnet 5.5 (agent-sdk provider, Operator subscription)
**Score:** interventions summed over two passes; fewer is better. Every arm solved 61/61 in every pass.
**Load:** 30 tasks in parallel on 8 cores / 31 GB.

A log of every lever tried, kept or rejected, so the same experiment is not run twice. Add a
row when an arm finishes; never delete a rejected one.

## Split

Tasks are split by family (the name less `-history`/`-amended`), 40% to holdout by
`sha1("sdebench-split-v1:" + family) % 100 < 40`: 43 dev tasks in 19 families, 18 holdout in 9.
Holdout families: budget, cachekey, csvquote, hostallow, mimemap, omdset, sched, slalog, slugify.
Levers are chosen from dev failures only, and one ships only when holdout does not get worse.
Levers chosen before the split (#243, #245, #246, #247, the Injection Gate) came from dev tasks only.

## Findings

- **Pass-to-pass noise is about ±5 interventions per arm** (main gate off: 9 then 14). A lever
  that moves the total by less than that over two passes has not been shown to work.
- **Gate on helps both arms** (main 23 → 19, v11 17 → 7). The Operator's default is on, so arms
  are now compared gate on.
- **A short-rule Summary prompt (v12) is harmful:** compressing decisions to one rule each
  dropped the conditions and exact values the hidden tests check.
- **The reranker is a serial bottleneck.** `ai.lan:9202` takes about 870 ms for a 30-candidate
  request when idle and serves one request at a time (3 concurrent: 0.9, 1.7, 2.6 s). Under 30
  parallel tasks the gate timed out on 23 of 89 Injections. The timeout and the amendment
  searches together pushed the Injection 1.7–5.2 s past the hook's start, beyond its 1.5 s wait.
  Every Injection logged within 1.5 s that carried the task's Summary scored 0 interventions.
  This led to v13.
- **The daemon records Injections the Agent never saw.** `noteInjection`
  (`src/triggers/api.ts`) records the Injection after it is built, even when the hook has
  already given up. Injection counts from a run therefore overstate delivery; compare the
  Injection's time against the hook's start instead.
- **`parseflag-history` is a benchmark defect.** Its commit says case-insensitive, but the
  hidden test asserts `parse_flag("On") is False`. Discount it from any comparison.
- **`redact-history` fails because its rule exists only in git history** (survey F4), and no
  Summary carries it.

## Harness pitfalls

- The arm (`sdebench/harness/agentmemory_arm.py`) is an untracked file in a local
  `vectorize-io/agent-memory-benchmark` checkout, so it is not backed up anywhere.
- Arms must not run concurrently against one `work/` tree: they share `work/sdebench/hist/<task>`.
- Each parallel task needs its own daemon instance (`SDE_AGENTMEMORY_INSTANCE`); there is one
  decoy template per checkout, built by a one-task warm-up before any parallel pass.
- The replay sandbox drops every env var not in `LLM_ENV` (`eval/runner/sandbox.ts`). Without
  the agent-sdk vars it silently summarizes with the default provider instead of Sonnet.
- `CLAUDE_CONFIG_DIR` must point at an empty directory, or the Operator's settings override
  `ANTHROPIC_MODEL`.
- A 30-way run can exhaust the subscription's session limit; discard any pass that hit it.
